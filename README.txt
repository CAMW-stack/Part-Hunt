PART HUNT GH — interactive website concept
========================================

FILES
- index.html : page structure and demo screens
- style.css  : responsive modern styling
- script.js  : navigation, search, media previews, demo cart and forms

HOW TO OPEN
1. Extract PART_HUNT_GH_Prototype.zip.
2. Open the folder.
3. Double-click index.html (or right-click > Open with your browser).
4. Internet is needed for Google Fonts and sample remote product/hero imagery. Core UI and interactions work locally.

NOTEPAD++
Open index.html, style.css and script.js in Notepad++ to edit the source.
Keep the three files in the same folder.

IMPORTANT
This is a front-end concept/demo. It does not connect to a live database, vendor accounts,
cloud media storage, payment gateway, messaging service, or delivery provider.
Product listings, prices, vendor stats and order flows are demonstration content.
